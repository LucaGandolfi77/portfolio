Privacy Policy

Ultimo aggiornamento: 1 settembre 2026

1. Nessun dato raccolto

Pixel Stretch non raccoglie, memorizza, o trasmette alcun dato personale. Tutte le operazioni — editing, layer, export, AI background removal — avvengono interamente sul tuo dispositivo. Nessun dato viene inviato a server esterni.

2. Nessun server

Pixel Stretch funziona interamente offline. Non esiste alcun server che raccoglie, memorizza, o elabora dati. Le immagini che carichi e i progetti che salvi rimangono esclusivamente nel tuo browser.

3. AI Background Removal

Le funzionalità di scontorno AI (Rapido e Preciso) utilizzano modelli machine learning che vengono scaricati sul tuo dispositivo al primo utilizzo. Una volta scaricati, funzionano completamente offline. I modelli vengono memorizzati nella cache del browser e non trasmettono dati a nessun server.

Modelli utilizzati:

• IS-Net (imgly) — ~40MB, licenza AGPL
• ormbg (Hugging Face Transformers) — ~44MB, licenza Apache 2.0

4. Nessuna pubblicità

Pixel Stretch non contiene pubblicità di alcun tipo.

5. Nessun tracker

Pixel Stretch non utilizza Google Analytics, Facebook Pixel, o qualsiasi altro servizio di tracciamento. Se installato tramite l'app web, nessun dato di navigazione viene raccolto.

6. Salvataggio progetti

Quando salvi un progetto, il file JSON viene salvato localmente sul tuo dispositivo (download diretto). Non viene inviato a nessun server.

7. Esportazione immagini

Le immagini esportate (PNG, JPEG, WebP) vengono generate localmente sul tuo dispositivo e scaricate direttamente. Nessuna elaborazione avviene su server.

8. Cookie

Pixel Stretch non utilizza cookie di tracciamento. Il service worker memorizza i file dell'applicazione localmente per permettere l'uso offline.

9. Service Worker

Il service worker (Workbox) memorizza i file dell'applicazione e i modelli AI nella cache del browser per permettere l'uso offline. Questa cache è locale al tuo dispositivo e non viene condivisa.

10. Google Play Store

Se Pixel Stretch è installato tramite Google Play Store, la distribuzione avviene tramite Trusted Web Activity (TWA). Il TWA non aggiunge funzionalità di raccolta dati rispetto alla versione web.

11. Modifiche

Eventuali modifiche a questa politica verranno pubblicate su questa pagina. La data dell'ultimo aggiornamento è indicata in alto.

12. Contatti

Per domande su questa privacy policy, contattaci all'indirizzo email indicato nel repository del progetto su GitHub.
