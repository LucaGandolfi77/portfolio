# Mindful Break
A lightweight PWA for hourly breathing breaks. Zero data, zero backend, zero account.

## Local dev
```bash
npx serve . -l 8080
```

## Manifest
Modified icons use SVG (no PNG dependency). Update before Play Store submission with proper PNG icons.

## Deployment
Copy contents to any static web server. Service worker caches shell assets. Web App Manifest supports SVG icons.
