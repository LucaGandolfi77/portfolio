Audio Transcriber

Use a local or browser-based transcription model (Whisper style) to transcribe audio files. This UI lets you pick a file or record live.
Select or record audio, then press Transcribe.

Come funziona

  • Puoi caricare un file audio usando il pulsante file.
  • Premi Record per iniziare la registrazione. Premi di nuovo per fermare.
  • Quando la registrazione è disponibile, premi Transcribe per ottenere il testo.
  • Questa demo usa una trascrizione simulata — sostituisci la chiamata API con il tuo backend Whisper.
