SHHH – Privacy Policy

Ultimo aggiornamento: 8 settembre 2026

1. Principio fondamentale

SHHH è progettato per funzionare interamente on-device. Non raccogliamo, trasmettiamo, salviamo su server o condividiamo alcun dato personale. Il rumore ambientale viene analizzato esclusivamente sul tuo dispositivo tramite il microfono.

2. Dati raccolti (nessuno)

SHHH non raccoglie dati personali. In particolare:

  • Nessun dato audio viene registrato, trasmesso o salvato
  • Nessun dato di localizzazione
  • Nessun dato di identità (account, email, nome)
  • Nessun identificatore del dispositivo inviato a server esterni
  • Le statistiche (tempo di lettura, streak) sono memorizzate localmente nel tuo dispositivo (localStorage)

3. Permesso microfono

SHHH richiede l'accesso al microfono per monitorare il rumore ambientale. Questo permesso:

  • Viene richiesto su gesto dell'utente (mai all'avvio automatico)
  • I dati audio vengono analizzati in tempo reale e non salvati
  • L'elaborazione avviene esclusivamente nell'analizzatore Web Audio API del dispositivo
  • L'utente può revocare il permesso in qualsiasi momento dalle impostazioni del browser

4. File scaricati

SHHH permette di aprire file locali (PDF, ePub, TXT, MD, HTML). Questi file:

  • Vengono elaborati interamente nel browser
  • Non vengono caricati su alcun server
  • Vengono archiviati nel filesystem locale del dispositivo

5. Pubblicità (tier gratuito)

La versione gratuita di SHHH può mostrare annunci pubblicitari. Per ridurre al minimo la privacy:

  • Le pubblicità sono non personalizzate (non usano il tuo profilo)
  • Non raccogliamo dati per la personalizzazione degli annunci
  • Gli inserzionisti non ricevono dati identificativi
  • L'attivazione degli annunci può essere rimossa con SHHH Pro (acquisto una-tantum)

6. Cookie e tecnologie simili

SHHH utilizza esclusivamente localStorage per salvare le preferenze dell'utente e le statistiche locali. Nessun cookie di tracciamento o di profilazione viene utilizzato.

7. Servizi esterni

SHHH utilizza le seguenti librerie CDN per il rendering di documenti:

  • pdf.js (Mozilla) — rendering PDF locale
  • epub.js — rendering ePub locale
  • marked — rendering Markdown locale

Queste librerie sono caricate da CDN ma elaborano solo file locali e non inviano dati a server esterni.

8. Diritti dell'utente

Essendo che non raccogliamo dati personali, non esistono diritti da esercitare. Puoi:

  • Svuotare le statistiche locali nelle impostazioni
  • Revocare il permesso microfono dal browser
  • Disinstallare l'app in qualsiasi momento

9. Contatti

Per domande sulla privacy: hello@shhhreader.app

Questa privacy policy è conforme al GDPR (Regolamento UE 2016/679) — in particolare agli articoli 5 (principi), 6 (legalità), 12 (trasparenza) e 13 (informazioni) per il trattamento minimo.
