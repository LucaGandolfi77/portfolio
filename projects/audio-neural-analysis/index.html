🎧 AUDIO NEURAL

How it works

Live microphone or audio file → FFT spectrum (Web Audio AnalyserNode) → 12 spectral features (band energies, centroid, rolloff, flux, zero-crossing, spread, flatness) → a tiny neural network 12→16→4 (tanh hidden + softmax) that predicts rock / classical / jazz / electronic. The neural corona shows the spectrum ring + 4 genre arcs driven by confidence. All on-device.

Honest note

The network is trained in your browser on synthetic genre profiles (GTZAN-inspired feature distributions) — not on real recordings, so on real music it reacts to actual spectral character (bass-heavy → rock/electronic, bright/sparse → classical…) rather than memorized songs. It's a live demo of the full audio-AI pipeline.

Technical

FFT 512 (desktop) / 256 (mobile) · features every ~250 ms, confidences smoothed · training: cross-entropy + SGD momentum, ~250 epochs on 1000 synthetic samples.
