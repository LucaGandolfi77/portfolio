L'app non si è avviata. Probabilmente stai aprendo questo file con un server statico (Live Server, VS Code, python -m http.server, doppio clic sul file…). Non basta: qui dentro c'è codice TypeScript/JSX che deve essere compilato.
  1. Apri il terminale nella cartella projects/verso-il-17
  2. npm install (solo la prima volta)
  3. npm run dev
  4. Apri l'indirizzo che compare, di solito http://localhost:5178
