🔑 RSA in breve

RSA è un cifrario asimmetrico: due chiavi legate matematicamente.

  • p, q — primi segreti
  • n = p × q — modulo pubblico
  • φ(n) = (p−1)(q−1)
  • e = 65537 — esponente pubblico
  • d = e⁻¹ mod φ(n) — esponente privato

Cifra: c = mᵉ mod n · Decifra: m = cᵈ mod n. Firma: hash(m)ᵈ mod n.

⚠️ Versione didattica: niente OAEP/PSS, chiavi piccole, messaggi monoblocco.
