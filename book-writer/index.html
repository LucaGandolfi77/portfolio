    ❓ Book Writer — FAQ

    What is Book Writer?

    Book Writer is an AI-powered novel generation assistant that helps you create complete novels chapter by chapter. It leverages large language models to generate plot ideas, write full chapters, and maintain story consistency across your entire book.

    You define your book's title, genre, tone, audience, and description. The AI then generates 5 unique plot directions for each chapter. You pick the best idea, and the AI writes the full chapter—including a title, the narrative text, and a continuity summary for the next chapter.

    It supports multiple AI backends: Ollama (fully local, free), OpenAI (GPT-4o and family), and Google Generative AI. Your books, progress, and settings are saved to localStorage, so everything persists between sessions.

    How does it work under the hood?

    The app is a browser-based SPA (Single Page Application) that communicates directly with AI providers via REST APIs—no backend server required.

    1. Book Setup — You provide metadata (title, genre, tone, description, audience). This becomes the "system prompt" that anchors all AI output.
    2. Idea Generation — The AI receives the full book context plus previous chapter summaries and returns exactly 5 plot directions in JSON format.
    3. Chapter Writing — You pick one idea. The AI writes the chapter in a structured format: TITLE: / CHAPTER_TEXT: / SUMMARY:. The summary is stored for continuity.
    4. Prompt Engineering — Writing options (dialogue, sensory detail, metaphor, interior monologue) and custom "prompt extras" are injected into every request.
    5. Persistence — All state (books, options, language) is serialized to localStorage on every change, surviving page reloads.

    Step-by-step example

    Imagine you want to write a science-fiction novel:

    1. Add a book — Click ＋, enter:
      Title: "The Last Observatory"
      Description: "A physicist discovers impossible signals from a coastal observatory."
      Genre: Science mystery | Tone: Atmospheric, tense
    2. Select the book — It becomes the active context for all AI calls.
    3. Generate Ideas — Click 💡 Generate 5 Ideas. The AI returns something like:
      Idea 1: A coded signal from a sunken ship...
      Idea 2: The storm returns every 19 years... ...
    4. Pick one idea — Click Idea 2. It gets highlighted.
    5. Write the chapter — Click ✍️ Write Selected Chapter. The AI produces a full chapter with a title, ~2500 words, and a summary.
    6. Repeat — Each new chapter builds on previous summaries for perfect continuity.
    7. Export — When finished, click 💾 Export to download your novel as a .txt file.
    Quick demo: Auto-Finish mode will loop steps 3–6 until all 20 chapters are complete, choosing idea #1 each time.

    Architecture

    This is a client-side-only web app. All AI calls go directly from the browser to the provider's API—no proxy or backend server is needed. The companion desktop app book-writer-gui.py is built with Python + Tkinter and offers the same features with file-based API key management.
