## Capitoli e Minigiochi

### Fase 1 — Le basi
1. 🏦 **Il Primo Soldo** — Budget, entrate/uscite → Banco di Lia (calcolo resto)
2. 🏪 **Il Mercato** — Domanda/offerta → Contrattazione (compra basso, vendi alto)
3. 🌳 **Il Salvadanaio Magico** — Interesse composto base → Albero interattivo
4. 🧮 **Il Segreto del Compound Interest** — Simulatore completo → Grafico SVG, slider, frequenze, inflazione

### Fase 2 — Debito e diversificazione
5. ⛓️ **La Trappola dell'Usuraio** — Debito → Runner infinito (schiva le bollette)
6. 🧺 **Non Tutte le Uova** — Diversificazione → Tre Cesti (allocazione portafoglio)

### Fase 3 — La battaglia
7. ⚔️ **Battaglia Finale** — Inflazione → Boss Quiz vs Inflazion 🐉 (10 domande, 100 HP)

### Fase 4 — Investimenti
8. 📊 **Le Azioni** — Borsa, proprietà → Borsa Virtuale (6 aziende, 8 round)
9. 🧩 **Gli ETF** — Fondi indicizzati → Costruisci il tuo ETF (5 settori)
10. 📜 **Le Obbligazioni** — Reddito fisso → Quiz Obbligazioni (BTP, Corporate, Zero Coupon, Green Bond)

### Fase 5 — Gestione finanziaria
11. 🏛️ **Le Tasse** — Fiscalità, scaglioni → Compila la Dichiarazione (scaglioni italiani)
12. 🛡️ **Le Assicurazioni** — Gestione rischi → Scegli l'Assicurazione (6 scenari)
13. 🏖️ **Le Pensioni** — Piano pensionistico → Calcola la Pensione (slider interattivi)

### Fase 6 — Avanzato (Post-Game)
14. ₿ **Le Criptovalute** — Blockchain, Bitcoin, rischi cripto → Boss Quiz
15. 🏠 **Immobili e Affitti** — Investimenti immobiliari, mutui → Simulatore
16. 🐉 **L'Inflazion Avanzata** — Iperinflazione, deflazione → Boss Quiz
17. ⚖️ **Etica e Finanza** — Investimenti ESG, greenwashing → ETF Builder
18. (Capitolo bonus unlocking)

### Impero di Soldania (Idle Game)

Sbloccato dopo il Capitolo 7:
- **12 edifici**: Limonata → Panificio → Bottega → Banca → Fondo Investimenti → Borsa Valori → Palazzo Reale → Fondo Sovrano → Università → Mercato Globale → Stazione Spaziale → Rift Dimensionale
- **16 miglioramenti**: building-specific x2/x3 + global multipliers x1.5/x2/x3/x5
- **4 eventi casuali con scelte**: Crisi di Mercato, Boom Economico, Truffa, Mappa del Tesoro
- **7 eventi classici**: Crisi, Boom, Scoperta Tesoro, Rimborso Tasse, Albero della Fortuna, Goccia d'Oro, Draghi Nemici
- **Manager system**: compra manager per guadagno automatico
- **Buy Max/Buy 10/25**: acquisto multiplo edifici
- **Prestige Tiers**: Tier 1 (×0.25/livelli), Tier 2 (×0.5, +1 manager), Tier 3 (×1.0, +2 manager)
- **Guadagni offline**: 50% efficienza, max 24 ore

## Deploy

### GitHub Pages (automatico)
Il deploy è automatico tramite GitHub Actions. Ogni push a `main` deploymenta su:
`https://lucagandolfi77.github.io/portfolio/games/regno-di-moneta/`

### Google Play Store (TWA)
```bash
# Installa Bubblewrap
npm install -g @nicedoc/nicedoc @nicedoc/nicedoc-cli

# Genera TWA
npx @nicedoc/nicedoc-cli init --config twa-config.json

# Build APK
cd android && ./gradlew assembleRelease

# Upload su Google Play Console
```

### Apple App Store (Capacitor)
```bash
# Installa dipendenze
npm install

# Aggiungi piattaforme
npx cap add ios

# Sync
npx cap sync

# Apri Xcode
npx cap open ios
```

### Verifica JS
```bash
# Controlla syntax di tutti i file JS
for f in js/*.js; do node --check "$f"; done
```
