# Il Regno di Moneta 💰

Impara educazione finanziaria salvando il Regno di Soldania dal drago Inflazion!

## Struttura

- **13 capitoli** con storia, dialoghi e minigiochi educativi
- **Impero di Soldania**: idle game incrementale infinito (sbloccato dopo il boss)

## Capitoli

### Fase 1 — Le basi
1. 🏦 **Il Primo Soldo** — Budget, entrate/uscite → Banco di Lia
2. 🏪 **Il Mercato** — Domanda/offerta → Contrattazione
3. 🌳 **Il Salvadanaio Magico** — Interesse composto base → Albero interattivo
4. 🧮 **Il Segreto del Compound Interest** — Simulatore completo → Simulatore con grafico SVG, contributi mensili, frequenze, inflazione

### Fase 2 — Debito e diversificazione
5. ⛓️ **La Trappola dell'Usuraio** — Debito → Runner infinito

### Fase 3 — La battaglia
7. ⚔️ **Battaglia Finale** — Inflazione → Boss Quiz vs Inflazion 🐉

### Fase 4 — Investimenti
8. 📊 **Le Azioni** — Borsa, proprietà → Borsa Virtuale
9. 🧩 **Gli ETF** — Fondi indicizzati → Costruisci il tuo ETF

## Simulatore Compound Interest (Cap. 4)

Il simulatore include:
- **Grafico SVG** con tre curve: composto, semplice, contributi
- **Slider interattivi**: investimento iniziale, contributo mensile, tasso, anni
- **Frequenza di capitalizzazione**: annuale, trimestrale, mensile, giornaliera
- **Inflazione**: valore reale ajustado
- **Confronto**: compound vs semplice con differenza in euro e percentuale
- **Formula**: FV = PV(1+r/n)^(nt) + PMT×[((1+r/n)^(nt)-1)/(r/n)]
